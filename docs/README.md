# AXZIO Docs

This directory defines the documentation architecture for the AXZIO interface
layer.

## Documents

- `AXZIO_SYSTEM_ROLE.md`: role, boundaries, and repository position
- `AXZIO_ARCHITECTURE.md`: high-level application architecture and integration
- `AXZIO_USER_FLOW.md`: primary user journey through the interface
- `AID_INTEGRATION.md`: AI.d responsibilities and interface integration model
- `IDENTITY_ENGINE_INTERFACE.md`: how Identity Engine outputs appear in AXZIO

## Documentation Standard

These documents are developer-facing. They describe how AXZIO should behave as
an application layer and how it should integrate with surrounding repositories.

They should not duplicate philosophy, ontology, or canonical theory from
`ne3ula-knowledge`.
